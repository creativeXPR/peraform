What changes

  • Big buttons → one ⋯ menu next to “Screen 1”: Keep this screen, Keep this look, Copy phone design to desktop, and Start this screen over (red, still asks first).
  • Long notes → ⓘ tips: hover or tap to read. “How to design” sits by the screen name; the “After this screen” note sits on its heading.
  • Groups fold away. Each heading shows its current choice (“Big question”, “Midnight”, “Always shown”), so a closed group still tells you what’s set. The panel remembers which ones you opened.
  • Layout tiles are tiny phones showing each layout with real pieces (your sample photos, a heading, answer boxes, the button) and a two-word feel. Hover one and its blocks drop into place.
  • Visibility is two picture choices: “In the flow” (the screen lit up between the others) or “Skipped” (a dashed gap). “Show only if” reads as a sentence, When [Your role] is [Teacher], on a warm card; “Or when…” adds another.
  • Style tiles are tiny live screens: each shows its own background, card, fonts, corners, options and buttons, with a one-line feel underneath. Hover one to watch its entrance (Playful bounces, Glass blurs in, Midnight glows). The chosen one gets a tick.
  • “After this screen” is a destination card: an arrow tile, “Next goes to”, and the screen by number and name. Click it for the list of screens (numbered) and “Submit the form”, with the current one ticked.
  • Smaller controls: 28px chips, 24px round swatches (the custom colour is a rainbow ring with a +), 13px text.
  • Footer: the keyboard shortcut list and a “How to design” link, in one quiet line.
  • The same compact style goes on the block Inspector (when a block is selected), so both panels match.

Design

Click a block to edit it. Drag to move: it snaps to the card’s edges and centre and to the other blocks (hold Alt to place freely). Shift-click, or drag a box on empty space, to select several and move or style them together. Drag the corners to resize and the round knob to rotate. Ctrl + scroll zooms; hold Space (or press H) and drag to move around.
